# Analyse — food-app-concept-imsourav.sketch

## Contenu du fichier

Fichier Sketch (4 écrans), concept d'app mobile de **livraison de repas** (type Swiggy / UberEats / Zomato) :

1. **Onboarding / Login** — fond violet, illustration, bouton "LOG IN WITH FACEBOOK"
2. **Liste / Explore** — recherche + géoloc, cartes produits (photo, titre, catégorie, note ⭐, temps de livraison, prix, avatars clients, bouton "ADD +")
3. **Détail produit** — photo plein cadre, titre, note + lien "See all reviews", adresse de livraison, "Apply Promo Code", CTA vert "ADD +"
4. **Avis clients** — liste avatar + nom + étoiles + commentaire + "Request to review"

Assets images : essentiellement des icônes (48×48, 68×68) + 2 photos stock génériques (sandwich œuf/avocat, burger) sans rapport avec le bánh mì.

## Pertinence pour OBANH MI

**Faible.** Ce concept est pensé pour une app de commande avec compte utilisateur, panier, livraison et code promo — OBANH MI est un site vitrine statique, sans ces fonctions.

Le style va aussi à l'opposé de la direction déjà prise sur le site (inspirée Junk Burgers : noir et blanc, épuré, flat, sans ombre, sans badges arrondis colorés) :

| Élément du concept | Style | Compatible avec OBANH MI ? |
|---|---|---|
| Cartes produit colorées + ombres | Material design coloré | Non |
| Étoiles de notation + avatars empilés | Suppose des comptes utilisateurs | Non |
| Bouton "ADD +" vert en pastille | Rounded, coloré | Non (le site est en boutons plats) |
| Login Facebook | Fonction compte | Non applicable |
| Code promo | Fonction panier | Non applicable |
| Layout carte produit (photo / titre / prix) | Structure générique | Déjà présent, en plus sobre, dans la grille menu actuelle |
| Liste d'avis clients | Structure générique | Récupérable **si** reformulée dans le style épuré du site |

## Recommandation

Ne pas s'inspirer de ce fichier pour l'esthétique du site — il tirerait OBANH MI dans une direction "app colorée" contraire au choix déjà fait (monochrome, flat, Bebas Neue).

Seule piste à garder : l'idée d'un bloc "avis clients" (si non déjà satisfait par l'intégration Facebook Reels existante) — mais à redessiner dans le style noir/blanc du site, pas en copiant les cartes colorées du concept.
